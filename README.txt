ALPHADEUTSCH - Gmail SMTP contact form

SETUP
1. Keep your existing CSS, images and other assets in this folder.
2. Copy .env.example to .env and put your own Gmail + App Password there.
3. Open a terminal in this folder:
   npm install
   npm start
4. Open http://localhost:3000

The server uses smtp.gmail.com, port 465, SSL.
The App Password stays on the server and is NOT placed in browser JavaScript.
Do not upload .env to GitHub or share it.
